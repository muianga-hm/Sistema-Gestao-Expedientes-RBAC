# Sistema-Gestao-Expedientes-RBAC

Sistema de Gestão de Expedientes com Controlo de Acesso Baseado em Papéis (RBAC).

## Descrição

O sistema permite gerir expedientes, utilizadores, papéis, movimentações, auditoria e relatórios, garantindo controlo de acesso conforme as funções de cada utilizador.

## Tecnologias

- Java
- Spring Boot
- Spring Data JPA
- Thymeleaf
- MySQL
- Maven

## Funcionalidades

- Gestão de utilizadores
- Gestão de papéis e permissões
- Gestão de expedientes
- Tramitação e movimentação de expedientes
- Registo de auditoria
- Relatórios
- Autenticação e controlo de acesso baseado em papéis (RBAC)
## Objetivo

O objetivo do sistema é melhorar a gestão e o acompanhamento dos expedientes, garantindo organização, segurança, rastreabilidade e controlo de acesso às informações.
